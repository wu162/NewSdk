# W3DAnimation 压缩优化

分支 `optimize/w3d-animation-compression`，基于 `recovery/legacy-sdk-cache` 的
`436115db594c405c1650d27754594454eed54bdc`。保留原版输出、误差设置、强制缩减目标、
BinaryMove、平台字节序、原估算公式及格式选择；不改变有损压缩精度。

## 实现

- Timecoded 用源帧索引邻接表替代 vector 中间删除。误差阶段只回到变化的前驱三元组，
  总扫描为线性；强制缩减阶段使用索引最小堆，每次只更新两个邻居，为 O(n log n)。
  并列按原帧顺序；四元数 w>=1 的无条件优先删除仍高于普通最小角误差。
- AdaptiveDelta 对非负累计误差设置当前最优值上界，提前结束不可能胜出的候选，
  遇首个零误差即停止搜索；每个通道/位宽按实际访问懒计算并复用步长和倒数。
  搜索不写临时编码，胜出滤波器完整编码；原 float/double 舍入点不变。
  有限常量通道直接生成原版 filter0/全零 delta，保留负误差返回失败和非有限输入拒绝。
- 两种压缩直接读取准备好的帧，删除生产路径的逐帧转换/深拷贝；只复制最终保留帧。
  准备结果与最终 delta 用 move 交接，预留通道和压缩块容量。
