# Loadable recovered W3X plugin

`Recovered.Compiler.W3x.NativePlugin, Recovered.W3x.Plugin` is a new configuration identity. Its parameterless constructor injects a private `IW3xAssetCompiler` implementation into the unchanged, previously accepted `Plugin` shell. Animation and mesh backends call the recovered C++/CLI component bridges with `declaration.Node`, its document namespace manager and selected platform. They never forward to the original W3X compiler.

`BuildW3xPlugin.ps1 -OutputDirectory <new-or-empty-path> -Mode Od|O2` builds x86 native sources, both component bridge assemblies and `Recovered.W3x.Plugin.dll`. It copies SDK runtime dependencies excluding `BinaryAssetBuilder.W3XCompiler.dll`, preserves independent build logs and writes build fingerprints. It does not modify the SDK configuration, masquerade as the original assembly or implement the unused original VC8 private pointer ABI.

`TestW3xPlugin.ps1 -CaptureDirectory <successful-native-run-directory> [-OutputDirectory <new-path>]` requires current-source complete component acceptance. It tests both optimization modes: configuration type resolution/public default constructor and actual ProcessInstance outputs against all675 animation plus666 mesh original captures, reruns original ProcessInstance comparison, and replays in a separate process that forbids loading the original W3X assembly. Direct public handlers are checked for the first fixture of each route. `plugin-validation.json` records actual results and build/capture fingerprints. SDK acceptance remains a separate subsequent gate.

For SDK verification only, an absolute `RECOVERED_W3X_TRACE_DIRECTORY` enables successful backend-call tracing. Each uniquely named `*.fixtures` file contains the existing BinaryWriter `W3X-FIXTURE-1` format, one animation/mesh route and one record with platform, preprocessed XML and all three actual result buffers. Unset environment means no tracing or extra writes. Trace failure fails the call rather than silently losing verification evidence. The independent SDK runner owns trace completeness, original replay and final SDK product comparison.
