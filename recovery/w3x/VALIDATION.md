# 验证框架与验收门槛

| 层级 | 必须记录/检查 | 当前含义 |
| --- | --- | --- |
| 原版取证 | 原 DLL SHA-256、sourceCommit、runId/attempt、工具版本、方法/布局/插件接口 | 只能证明原版证据可复现 |
| 恢复版构建 | x86 C++/CLI + .NET Framework；native /Od 和 /O2 | 编译通过不能证明输出相同 |
| 组件差分 | 相同合法输入、平台0/1/2/99、Instance/Relocation/Imports 三缓冲区逐字节；拒绝与异常行为 | 数值平台含义和99行为先核实 Core/原版；不能预设99成功 |
| 独立断言 | 结构大小/偏移/对齐、分配顺序、endian、引用、位模式、重复调用不变性 | 不能只有实现与自身生成期望的循环验证 |
| 共享重构 | 原有所有受影响组件及 W3X 完整矩阵 | 不明影响范围时扩大验证 |
| SDK 接管 | XSD 合法样例、实际插件调用记录、相同依赖和缓存条件、完整相关产物对比 | 必须证明路由实际命中新实现 |
| 完整替换 | 全部目标分支、完整 mymod、无原 W3X DLL 重放、身份/部署/版本行为 | 与组件通过独立记账 |

后续 fixture 至少按实际支持能力涵盖：最小和空数据、缺省值、scalar/quaternion 通道、关键帧/时间边界、压缩分支、全部顶点属性组合、顶点/索引/骨骼边界、平台数据格式、引用和非法输入。列表是设计目标，不能在尚未读原合同前假设每种输入都被原版接受。浮点、四元数、half、归一化字节等以原版位模式为准，不使用宽松 epsilon 掩盖差异。

原版与恢复版最好以独立 x86 宿主进程执行，隔离全局状态/程序集绑定；以可追溯的原版三缓冲区作为 oracle。当前 `W3xPluginContractOracle.cs` 仅枚举原版公开接口，不实例化插件、不调用 ProcessInstance、不比较任何恢复实现，PASS 文案限定为 contract inventory。

完整批次准备好后统一跑受影响 /Od、/O2 矩阵；定向探针用于解释未知行为，不代替最终矩阵。SDK 在更大里程碑集中运行；可使用一次性精简 MOD，但保留必要依赖并记录精简范围。正式接管前保留完整 mymod 验收。不得复用原项目测试计数冒充 W3X 通过。

证据目录只追加。`extraction.json` 的 sourceCommit 指向被取证的源码提交，不是自动保存证据的提交；`recoveredBehaviorValidated=false`、`sdkValidated=false` 在取证阶段始终保留。失败保留 artifact；成功取证由工作流普通推送到当前分支。解读结果时核实 workflow/job 终态及各 exit code；C# rendering 失败须明确记录，不影响已成功取得的原始 IL/PE 证据，但禁止宣称完整反编译成功。
