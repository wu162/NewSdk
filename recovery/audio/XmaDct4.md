# DCT-IV: 0xa81db

The complete 755-byte, 284-instruction table-backed `a81db..a84ce` DCT-IV is recovered in `XmaDct4.cs`, including pre-rotation, the recovered forward FFT, post-rotation and original binary32 store points. Its domain is N in {64,128,256,512,1024,2048}; larger/unlisted sizes enter unrecovered trigonometric paths.

The native ABI is stdcall nine arguments: in-place float[N] data, float scale, optional output integer pointer, N, FFT callback, and four unused arguments; `ret 0x24`, HRESULT zero. The optional output becomes zero. The callback receives complex order log2(N)-1, forward direction zero. The actual call `97bb0: call [eax+1f0]` uses a81db; its FFT callback is a7de3. Original coefficient pointers d4c38+(N>>7)*4 select d4afc/d4b30/d4b64/d4b98/d4bcc/d4c00. Eleven exact float bit patterns per size, including the recurrence factor at index 10, are embedded.

Actual CPU acceptance: source `d3f96009e64b44c4d9482421cc5922b3309320bc`, Actions run `40236037500`. The new 360 synthetic cases and 111 captured actual codec-transform inputs matched every original CPU output bit, HRESULT and optional output in recovered Debug/Release hosts; nine independent safe refusals passed. Raw capture retained all original arguments, input/output hashes and actual callback targets, and all three full raw outputs stayed equal to the accepted baseline. The accepted FFT matrix was not rerun or modified.

`TestAudioXmaDct.ps1` uses `xma-dct-validation`; `-SnapshotsDirectory .../transforms -RealOnly` uses `xma-dct-replay-validation` and replays only captured inputs. Candidate hosts exclude the original DLL; the original DLL is SHA pinned and actual physical x87 CW 027f is verified and restored. Computation uses a private working array and copies back only on success: finite but overflowing pre-rotation inputs may fail the recovered FFT finite-input check, with caller data intact. Such safe refusals are separate from the finite-FFT-intermediate equivalence domain. This is a numerical backend group, not quantization, entropy coding or a public encoding route.
