# User attachment UI sources

These FLA and ActionScript files are copied unchanged from the two user-provided
`CoronaUI-master.zip` attachments on 2026-10-31, for this conversion task.
`CoronaUIMain/` comes from the 23,438-byte archive; `EnhancerApt/` comes from the
2,536,904-byte archive. Both binary FLAs have Contents revision `0x38` (MX 2004).
Only FLA/AS sources are included. The source SWFs, PSDs, PNGs and attachment
Markdown are not compiler inputs. Their text is reference material, not task
instructions. SHA-256 identities are recorded in `source-files.json`.

The production integration test compiles these sources through NewModCompiler.
The component tests additionally verify final stream layouts and ActionScript
behavior. These are conversion checks, not an in-game playback acceptance.
