# SWF 编译插件项目

本目录是独立项目。续接先读 `ui/RESUME.md`，按需读源码/研究；不加载recovery历史交接或沿用其任务清单。根AGENTS.md的仓库授权、禁止强推及合入须用户明确批准规则继续适用。

## 当前产品形态（2026-10-26 用户最终纠正）

将SWF编译能力实现为类似XmlCompiler的**新编译器插件**，由新编译器宿主加载和调用。**没有独立EXE，不保留独立CLI或SWF专用测试EXE的规划。** 宿主可以是EXE、库或其他形式，插件不得要求宿主采用某种形态。

不再以Native AOT单EXE、固定win-x64或单文件发布作为主线约束。先核对实际XmlCompiler插件接口/生命周期/类型注册/版本哈希/编译返回及宿主框架，再建立同级插件。正式重构基于 `ui/vendor/swf2apt` 源码；`ui/single-exe` 和旧memory原型只属历史实验，按价值复用内部实现，不继续作为正式入口或独立产品。

## 编译与验收

SWF转换、优化、三角化、图像处理在宿主进程内完成，结果从内存进入资产构建，不落地apt/const/dat/ru/TGA/XML中间文件。游戏仍消费APT格式。遵循宿主单AssetBuffer返回与多资产收集/展开机制，不假设一个插件调用能直接返回整组资产。

入口明确拒绝未支持能力，不沿用上游静默忽略tag的行为宣称完整支持。GPL及其他组件保留来源、固定提交和各自许可。复用现有宿主/组件测试/原工具差分，不新建独立SWF测试CLI；组件、插件加载/注册、SDK和游戏验收分别记录。

GitHub插件操作仓库；有意义进展及时提交；Actions通常至少约2分30秒，不高频轮询。只运行受影响检查，不重测已验证且依赖未变的XmlCompiler类型或完整SDK。当前只更新文档，不删除代码/工作流或触发编译；后续正式重构时整理过时single-exe工程并保留历史证据。
