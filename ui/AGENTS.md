# SWF 直接编译项目

本目录是独立项目。续接只先读 `ui/RESUME.md`，按需读 `ui/RESEARCH.md` 和代码；不加载 recovery 的历史交接或沿用其任务清单。根 AGENTS.md 的仓库授权、禁止强推和合入须用户明确批准规则继续适用。

复用运行经验：仓库读写用 GitHub 插件；有意义进展及时提交；Actions 通常至少约 2 分 30 秒，等待期间做独立工作，不高频轮询。只运行本目录受影响检查，不触发已验证且未变化的 XmlCompiler 类型或完整 SDK 回归。组件差分、真实 SDK 集成和游戏验收分开表述，不能相互冒充。

目标：MOD 编译器接受 SWF，转换结果从内存进入资产构建，不落地 apt/const/dat/ru/TGA/XML 中间文件；游戏仍消费 APT 格式的最终资产。临时文件转换后删除不算实现目标。

入口处必须明确拒绝未支持的 SWF 能力，不能沿用上游静默忽略 tag 的行为宣称完整支持。GPL 上游代码和修改保留来源、固定提交和许可证。未经差分及 SDK 验证不启用生产路由。
